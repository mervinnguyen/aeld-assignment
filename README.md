# Introduction to Buildroot — CU Boulder ECEA 5305

Coursework repository for the "Linux System Programming and Introduction to
Buildroot" course, part of the Real-Time Embedded Systems Specialization,
M.S. Electrical & Computer Engineering, University of Colorado Boulder.

## Structure
Each assignment has its own directory with source, build files, and notes.
See individual READMEs where present.

## Target hardware
- Raspberry Pi 5B (external RTC, accessed via Tailscale VPN)
- Toolchain: Ubuntu Server host, Buildroot, cross-compiled for target
